# The UX Review

A modern, bold, and responsive blog website.

## Technologies Used

- **HTML5:** Semantic structure and accessible markup.
- **CSS3:** Styling, layouts, transitions, and animations.
- **Responsive CSS:** Media queries for different screen sizes.
- **Font Awesome:** Icons.
- **Google Fonts:** Custom typography.

## Getting Started

Follow these steps to run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/gamalshamy/the-ux-review.git
   ```

2. Navigate to the project folder:

   ```bash
   cd the-ux-review
   ```

3. Open `index.html` in your browser or use the **Live Server** extension in VS Code.

## Responsive Design

The website is designed to adapt to different screen sizes, providing a consistent browsing experience across:

- Desktop
- Laptop
- Tablet
- Mobile
